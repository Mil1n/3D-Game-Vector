## ⚡ Коротко об игре

| | |
|---|---|
| 🎯 **Жанр** | быстрый одиночный sci-fi FPS + roguelite-улучшения |
| ⏱️ **Забег** | целевой темп около 7 минут, жёсткий лимит — 10 минут |
| 🗺️ **Контент** | 3 процедурные арены, 5 видов оружия, 2 обычных противника и элитный босс |
| 🖥️ **Платформа** | браузер на компьютере, WebGL 2, клавиатура и мышь |
| 🎧 **Ассеты** | геометрия, VFX и звук создаются процедурно во время запуска |
| 💾 **Прогресс** | локальный профиль, статистика, опыт, рекорды и обучение |

Игра не загружает внешние модели, текстуры или аудиофайлы во время работы. Арены и оружие собираются из оптимизированной процедурной геометрии, а отдельные звуковые слои синтезируются через Web Audio API.

## 🌀 Твой забег

<div align="center">
  <strong>🎯 АКТИВИРУЙ → ⚔️ ВЫЖИВИ → 🌀 АДАПТИРУЙСЯ → 👑 УНИЧТОЖЬ СТРАЖА → 🚪 ЭВАКУИРУЙСЯ</strong>
</div>

| Фаза | Рубеж | Что происходит |
|---|---:|---|
| `01` 🔎 **Разведка** | `0:00` | вход в комплекс, первый узел и знакомство с угрозой |
| `02` ⚔️ **Эскалация** | не раньше `1:10` | динамическая задача и плотные волны противников |
| `03` 🌀 **Сдвиг** | не раньше `2:40` | перестройка арены, новая аномалия и выбор улучшения |
| `04` 👑 **Охота** | не раньше `4:00` | появление многофазного Стража Разлома |
| `05` 🚪 **Эвакуация** | не раньше `5:40` | удержание финального канала под максимальным давлением |

Если задача выполнена слишком рано, директор не оставляет пустую паузу: HUD включает интервал выживания с обратным отсчётом, а волны продолжают поддерживать напряжение. Пауза и экран выбора улучшения не расходуют игровое время. На `10:00` окно эвакуации закрывается — бесконечно зависнуть в забеге нельзя.

## 🌀 Сдвиг реальности

Обычно раз в 60–90 секунд комплекс предупреждает о перестройке. После пятисекундного сигнала арена безопасно меняет мосты, двери, укрытия и доступные маршруты, а бой получает один понятный модификатор:

- 🌙 **Разреженная масса** — ниже гравитация и выше прыжки;
- ⚡ **Кинетический резонанс** — быстрее движение и восстановление рывка;
- 🌩️ **Энергетический шторм** — усиливается энергетическое оружие;
- 📦 **Карман снабжения** — открывается резервный сектор с ресурсами.

Сдвиг не создаёт геометрию поверх игрока. Если позиция небезопасна, перестройка откладывается и повторно предупреждает о риске.

## 🔫 Собери свой арсенал

Все пять видов оружия доступны в каждом забеге. У каждого — собственный процедурный силуэт от первого лица и прицельный профиль, а энергетические узлы ARX, PX-7 и HMX-1 дополнительно анимированы. Переключайся клавишами `1`—`5` или колесом мыши.

| Оружие | Роль | Лучший сценарий |
|---|---|---|
| ⚙️ **VX-9 «Импульс»** | автоматический карабин | стабильный огонь на средней дистанции |
| 💥 **SG-4 «Осколок»** | кинетический рассеиватель | мощный ближний бой и зачистка проходов |
| 🎯 **ARX «Нуль-копьё»** | точная энергетическая винтовка | дальние цели, критические зоны и прострел линий |
| ⚡ **PX-7 «Поток»** | мобильный плазменный автомат | шквал ярких импульсов вблизи и на средней дистанции |
| 🌌 **HMX-1 «Сверхнова»** | тяжёлая имплозионная пушка | медленный заряд с взрывом по площади против группы целей |

У каждого ствола свои урон, темп, магазин, резерв, перезарядка, разброс в движении и при прицеливании, отдача, дальность, падение урона, аудиопрофиль и цвет эффектов. Препятствия проверяются раньше целей, поэтому выстрелы не проходят сквозь стены.

## 👾 Кто попытается тебя остановить

| Противник | Поведение |
|---|---|
| 🪖 **Контурный стрелок** | держит среднюю дистанцию, меняет позицию и атакует короткими телеграфированными очередями |
| 🗡️ **Фазовый охотник** | обходит с фланга, быстро сближается и наказывает за неподвижность |
| 👑 **Страж Разлома** | многофазовый элитный противник со щитом, веером энергетических сфер и опасными зонами |

У каждого типа свой процедурный силуэт и риг: винтовка с последовательными индикаторами очереди у Стрелка, парные клинки и фазовые плавники у Охотника, реактор, пилоны и вращающаяся корона у Стража. Телеграфы атак анимируют именно оружие и энергетические узлы, а снаряды появляются из авторских muzzle/core-якорей.

При выборе точки появления приоритет отдаётся позициям вне прямой видимости игрока. Система жетонов атаки ограничивает число одновременно атакующих обычных врагов, поэтому давление остаётся высоким, но читаемым.

## 🚀 Запуск за минуту

### Требования

- Node.js `20.19+`;
- npm `10+` или pnpm `10+`;
- современный браузер на компьютере с WebGL 2, IndexedDB и Web Audio;
- клавиатура и мышь.

### npm

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite — обычно это `http://127.0.0.1:5173`. Не запускай `index.html` двойным кликом: ES-модулям нужен локальный HTTP-сервер.

<summary><strong>📦 Использую pnpm</strong></summary>

```bash

```

</details>

### Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы появятся в `dist/`. Относительный `base: './'` позволяет разместить сборку не только в корне домена.

| Группа | Действие | Клавиша |
|---|---|---|
| 🏃 Движение | движение | `W A S D` или стрелки |
| | прыжок | `Space` |
| | спринт | `Shift` |
| | приседание / скольжение | `C` или `Ctrl` |
| | энергетический рывок | `Q` или средняя кнопка мыши |
| 🔫 Бой | стрельба | левая кнопка мыши |
| | прицеливание | правая кнопка мыши |
| | перезарядка | `R` |
| | оружие | `1`—`5` или колесо мыши |
| 🎯 Мир | взаимодействие | `E` |
| 🖥️ Система | пауза | `Esc` |

Pointer Lock включается после старта или продолжения. Если браузер его не поддерживает, canvas сохраняет клавиатурное управление, а обзор переходит в drag-to-look: зажми кнопку мыши и тяни курсор. Повторный клик снова попробует включить Pointer Lock.

## 🎛️ Настройки, доступность и сохранения

В игре применяются и сохраняются яркость сцены, DPR, тени, частицы, FOV, FPS cap, громкости отдельных шин, чувствительность мыши, инверсия Y, hold/toggle для ADS и crouch, масштаб UI, head bob, высокий контраст и цвет прицела. Fullscreen запрашивается только из пользовательского жеста.

`SaveManager` хранит версионированный профиль в IndexedDB: статистику, опыт, рекорд, состояние обучения и дату запуска. Малый snapshot настроек остаётся в localStorage, чтобы важные параметры были доступны ещё до открытия базы. Удаление прогресса требует явного подтверждения.

## 🐞 Debug Mode

Нажми `F3`, чтобы открыть диагностическую панель:

- FPS, frame time, draw calls, triangles и оценка памяти;
- активные враги, частицы, позиция и скорость игрока;
- ближайшее состояние ИИ, фаза директора и текущая аномалия;
- collision, spawn, objective и navigation overlays;
- god mode, бесконечные патроны, принудительный Сдвиг, завершение задачи и рестарт.

<details>
<summary><strong>🏗️ Архитектура и состояния</strong></summary>

Игровые системы не изменяют DOM друг друга напрямую. Они публикуют события через `EventBus`; `UIManager` отображает данные, а `Game` контролирует жизненный цикл. `InputManager` преобразует устройства ввода в action-состояния, физика работает фиксированными шагами, а match-time обновляется только игровым циклом.

Основные состояния: `Boot`, `Loading`, `MainMenu`, `Tutorial`, `Playing`, `Paused`, `UpgradeSelection`, `Victory`, `Defeat`. Недопустимые переходы отклоняются автоматом состояний.

</details>

<details>
<summary><strong>🧩 Расширение контента: оружие, враги, улучшения, аномалии и карты</strong></summary>

### 🔫 Оружие

1. Добавь полный объект в `src/configs/weaponConfigs.js`.
2. Добавь его `id` в `WEAPON_ORDER`.
3. Создай выразительную процедурную форму в `createWeaponModel()` файла `src/combat/WeaponSystem.js`.
4. Для нового принципа выстрела расширь `tryFire()` / `traceShot()`, сохранив проверку ближайшего world-hit.
5. Запусти тесты и проверь стрельбу, reload, смену оружия и рестарт матча.

### 👾 Противник

1. Добавь data-driven конфигурацию в `src/configs/enemyConfigs.js`.
2. Создай читаемый силуэт и именованный анимационный риг в `src/combat/enemyVisuals.js`.
3. Реализуй принятие решений через общие perception, navigation, attack tokens и projectile/hazard pools.
4. Подключи тип в `RunDirector.updateSpawning()` и проверь safe spawn / LOS.

### 🧬 Улучшение

Добавь запись в `src/configs/upgradeConfigs.js` с уникальным `id`, редкостью, лимитом стаков и объектом `effects`. Поддерживаемые эффекты централизованно применяет `UpgradeSystem.applyEffects()`; новый эффект нужно реализовать там и в системе-получателе.

### 🌀 Аномалия Сдвига

1. Опиши модификатор в `ANOMALIES` файла `src/systems/RunDirector.js`.
2. Добавь безопасную перестройку в `Arena.beginShift()` и `Arena.applyShift()`.
3. Примени gameplay-модификатор через `RunDirector.setAnomaly()`.
4. Проверь предупреждение, паузу, безопасность позиции и восстановление после рестарта.

### 🗺️ Карта

Карты описываются в `src/configs/mapConfigs.js`. Новый полигон должен получить уникальный `id`, пункт в меню и:

- статические cannon-es коллайдеры;
- читаемые маршруты минимум с двумя выходами из ключевых секторов;
- waypoint-связи и безопасные точки появления;
- корректный world raycast;
- валидные objective points;
- безопасные состояния до и после Сдвига.

После изменения проверь все навигационные циклы карты и возможность вернуться к ключевым секторам.

## ⚠️ Границы vertical slice

- только одиночный режим — без лобби, матчмейкинга и сетевого транспорта;
- только клавиатура и мышь на компьютере — геймпад и мобильный ввод пока не поддерживаются;
- компактный waypoint graph и локальный steering вместо тяжёлого runtime-navmesh;
- процедурный звук вместо финального студийного sound pass;
- без SSAO, настоящего motion blur и texture streaming ради стабильной работы на интегрированной графике.
